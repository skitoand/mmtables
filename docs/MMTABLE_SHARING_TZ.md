# ТЗ: пользователи, совместный доступ и публичные ссылки

**Проект:** MIndMapTable / Table Workspace  
**Версия:** 1.0  
**Дата:** 2026-06-26  
**Статус:** согласование

---

## 1. Цель

Реализовать полноценную работу с **личными аккаунтами** и **совместным доступом к документам** без организаций и мультитенантности.

Каждый пользователь:

- регистрируется и входит в свой аккаунт;
- создаёт и редактирует **свои** документы;
- делится документами с другими по email;
- может включить **публичную ссылку** — просмотр документа **без входа**.

**Вне scope (v1):** организации / tenants, subdomain, биллинг, SSO кроме Google, публичное редактирование, публичные комментарии без логина.

**Известные проблемы:**

- `canEditCurrentDocument()` в клиенте объявлен, но **не используется** — viewer видит полный редактор до 403 при сохранении.
- Активный документ хранится в session, не в URL — нельзя открыть документ по прямой ссылке.
- Guest/localStorage режим в коде есть, но при старте без логина приложение блокируется.

## 3. Модель пользователя

### 3.1. Аккаунт

- Уникальный `email` (PK).
- `password_hash` (PBKDF2-SHA256) или `auth_provider=google`.
- `name` / `display_name`.
- UUID `id` (уже есть в схеме).

### 3.2. Доработки auth (не блокируют v1)

| Задача | Приоритет |
|--------|-----------|
| Профиль: имя | P2 |
| Смена пароля | P2 |
| После регистрации — сразу рабочий стол | P1 |
| Приглашённый без пароля — экран «задайте пароль» / Google | P1 |
| `Secure`, `HttpOnly`, `SameSite` для session cookie на prod | P1 |

**Вне scope v1:** верификация email, восстановление пароля, удаление аккаунта.

---

## 4. Модель документа

- Документ принадлежит **владельцу** (`user_documents.email`).
- Содержимое — `layout_json` (фигуры, таблицы, коннекторы, zoom и т.д.).
- Пользователь видит: **свои** документы + документы из `document_access`.
- Удалять документ может только **owner**.

## 5. Права на документ

### 5.1. Роли

| Роль | Как выдаётся | Просмотр | Комментарии | Редактирование | Управление доступом | Удаление |
|------|----------------|----------|-------------|----------------|---------------------|----------|
| **viewer** (`reader`) | email / публичная ссылка | ✅ | ❌ | ❌ | ❌ | ❌ |
| **commenter** | email | ✅ | ✅ | ❌ | ❌ | ❌ |
| **editor** | email | ✅ | ✅ | ✅ | ✅ | ❌ |
| **admin** | email | ✅ | ✅ | ✅ | ✅ | ❌ |
| **owner** | владелец | ✅ | ✅ | ✅ | ✅ | ✅ |

- В UI роль `reader` отображать как **«Просмотр»**.
- **Публичная ссылка** всегда даёт уровень **viewer** (только просмотр).

### 5.2. Поведение UI по роли

| Роль | Toolbar | Drag / resize | Создание объектов | Сохранение | Share |
|------|---------|---------------|-------------------|------------|-------|
| viewer / гость по публичной ссылке | зум, «Войти» | ❌ | ❌ | ❌ | ❌ |
| commenter | + комментарии | ❌ | ❌ | ❌ | ❌ |
| editor | полный | ✅ | ✅ | ✅ | ✅ |
| admin / owner | полный | ✅ | ✅ | ✅ | ✅ |

### 5.3. Способы выдачи доступа

1. **По email** (есть) — приглашение существующему или новому пользователю (stub в `users`).
2. **Публичная ссылка** (новое) — просмотр без логина по URL с токеном.

## 6. URL и маршрутизация

### 6.1. Схема адресов

```
https://mmtable.skitovich.ru/login
https://mmtable.skitovich.ru/register
https://mmtable.skitovich.ru/                    → редирект на /d/{последний} или список
https://mmtable.skitovich.ru/d/{doc_id}          → документ (нужен вход + ACL)
https://mmtable.skitovich.ru/p/{doc_id}/{token}  → публичный просмотр без логина
```

Пример публичной ссылки:

```
https://mmtable.skitovich.ru/p/ac97f343-2d63-458a-97d4-fb5a6b86d863/a8f3k9m2x1q7…
```

### 6.2. Сервер

Все перечисленные пути (кроме API и static) отдают `index.html` (SPA).

```
GET /d/<doc_id>              → index.html
GET /p/<doc_id>/<token>      → index.html
```

### 6.3. Клиент

- Парсинг `pathname` → режим: `authenticated` / `publicGuest`.
- **Источник истины** для открытого документа — URL, не только session.
- `history.pushState` при смене документа без перезагрузки.
- Кнопка **«Скопировать ссылку»** в меню документа.
- После логина — редирект на запрошенный `/d/{id}`.

### 6.4. Обратная совместимость

- Старые закладки `/` + session → редирект на `/d/{active_doc_id}`.
- Существующие API (`/api/docs`, `/api/layout`) сохраняются; расширяются, не ломаются.

## 7. Публичные ссылки без логина

### 7.1. Модель данных

```sql
ALTER TABLE user_documents ADD COLUMN public_link_enabled INTEGER NOT NULL DEFAULT 0;
ALTER TABLE user_documents ADD COLUMN public_link_token TEXT UNIQUE;
ALTER TABLE user_documents ADD COLUMN public_link_created_at TEXT;
ALTER TABLE user_documents ADD COLUMN public_link_rotated_at TEXT;
```

- **Токен:** `secrets.token_urlsafe(32)` — криптостойкий, не угадываемый.
- **Включение / выключение / ротация** — только `owner` или `admin`.
- При ротации старый token → `404`.

### 7.2. API

| Метод | Путь | Auth | Описание |
|-------|------|------|----------|
| GET | `/api/docs/{id}/public-link` | owner/admin/editor | статус, URL (относительный) |
| POST | `/api/docs/{id}/public-link` | owner/admin/editor | включить или rotate token |
| DELETE | `/api/docs/{id}/public-link` | owner/admin/editor | выключить публичный доступ |
| GET | `/api/public/p/{doc_id}/{token}` | **нет** | layout read-only (JSON) |
| GET | `/p/{doc_id}/{token}` | **нет** | SPA, гостевой режим |

Запрещено для публичного токена: `POST /api/layout`, `PUT /api/docs/{id}` → **403**.

### 7.3. Клиент (гостевой режим)

- Флаг `guestPublicView = true` без `session.email`.
- Toolbar: зум, кнопка «Войти».
- Read-only: без drag, resize, создания, сохранения.
- Шапка: **«Публичный просмотр · {имя документа}»**.

### 7.4. Share modal (владелец)

- Переключатель «Публичная ссылка».
- Поле URL + «Копировать».
- «Обновить ссылку» (rotate).
- Предупреждение: *«Любой, у кого есть ссылка, сможет просматривать документ»*.

### 7.5. Безопасность

| Риск | Мера |
|------|------|
| Перебор token | длинный token; rate limit на `/api/public/…` |
| Утечка списка документов | публичный API отдаёт только один layout |
| Индексация поисковиками | `X-Robots-Tag: noindex` на `/p/…` |
| Clickjacking | `X-Frame-Options: SAMEORIGIN` / CSP |
| Устаревшая ссылка после rotate | 404 |
| Анонимные комментарии | в v1 **запрещены** |

## 8. Комментарии (фаза 5, опционально)

Только для **залогиненных** пользователей с ролью `commenter` и выше. Публичная ссылка комментирование **не даёт**.

```sql
CREATE TABLE document_comments (
  id TEXT PRIMARY KEY,
  document_id TEXT NOT NULL,
  author_email TEXT NOT NULL,
  anchor_type TEXT NOT NULL,   -- shape | cell | point | document
  anchor_json TEXT NOT NULL,   -- { shapeId, cellRef, x, y }
  body TEXT NOT NULL,
  status TEXT NOT NULL DEFAULT 'open',  -- open | resolved
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
```

| Метод | Путь | Права |
|-------|------|-------|
| GET | `/api/docs/{id}/comments` | viewer+ |
| POST | `/api/docs/{id}/comments` | commenter+ |
| PATCH | `/api/docs/{id}/comments/{cid}` | автор или admin |
| POST | `/api/docs/{id}/comments/{cid}/resolve` | editor+ |


**Приёмка:** ссылка `/d/{id}` открывает документ у пользователя с доступом.

### Этап 2 — Read-only для viewer (~1 нед.)

- [ ] Подключить проверки прав во всём UI

**Приёмка:** viewer не двигает фигуры и не сохраняет.

**Приёмка:** editor сохраняет; viewer — нет; admin управляет доступом.

### Этап 4 — Публичные ссылки без логина (~1–1.5 нед.)

**Приёмка:** инкогнито по ссылке видит схему, не может редактировать; после rotate старая ссылка — 404.

### Этап 5 — Комментарии (~2 нед., опционально)

## 12. Миграции и деплой

1. Backup `workspace.db` (локально и prod) — **перед каждым этапом**.
2. Скрипт миграции в `scripts/migrate_*.py`.
3. Деплой через `scripts/deploy_prod.sh` — только целевые файлы, не «весь app.js вслепую».
4. После деплоя — smoke test: логин, открытие документа, share, публичная ссылка.

## 13. Критерии приёмки (релиз v1)

- [ ] Пользователь регистрируется и создаёт документ.
- [ ] Документ открывается по `/d/{id}` после входа.
- [ ] Viewer по email видит документ без возможности редактирования.
- [ ] Editor сохраняет изменения.
- [ ] Admin выдаёт и отзывает доступ.
- [ ] Owner включает публичную ссылку; гость без логина просматривает документ.
- [ ] Ротация публичной ссылки инвалидирует старую.
- [ ] Нет регрессии формул, коннекторов, таблиц на существующих документах.
