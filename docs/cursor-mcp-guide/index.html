Подключить MM Table к Cursor

Короткая инструкция для сотрудников: после настройки Cursor сможет читать и менять ваши таблицы в MM Table через чат с агентом.

https://mmtable.crystalsystems.ru/mcp

Обычно занимает 3–5 минут.

Нужны: аккаунт в MM Table и установленный Cursor. Токен mmt_… — как пароль: никому не пересылайте и не выкладывайте в чаты/Git.

1 Войдите в MM Table

  1. Откройте https://mmtable.crystalsystems.ru
  2. Войдите своим корпоративным email и паролем

2 Создайте токен MCP

  1. Вверху слева откройте меню → Профиль
  2. Найдите блок MCP / Cursor / Claude
  3. В поле «Имя токена» можно написать, например: Мой Cursor
  4. Нажмите Создать токен
  5. Появится строка вида mmt_… — сразу нажмите Копировать токен
Токен показывается только один раз. Если закрыли окно — создайте новый.

3 Скопируйте готовый конфиг

В том же блоке профиля нажмите Копировать конфиг.

В буфере окажется JSON примерно такого вида (у вас будет ваш токен вместо примера):

{
  "mcpServers": {
    "mmtable": {
      "url": "https://mmtable.crystalsystems.ru/mcp",
      "headers": {
        "Authorization": "Bearer mmt_ваш_токен"
      }
    }
  }
}

Если токен ещё не создали — в конфиге будет плейсхолдер <PASTE_TOKEN_HERE>. Замените его на свой mmt_….

4 Вставьте конфиг в Cursor

Самый простой способ:

  1. Откройте Cursor
  2. Нажмите Cmd + Shift + J (Mac) или Ctrl + Shift + J (Windows)
  3. Слева выберите Tools & MCP
  4. Нажмите New MCP Server / откройте файл конфигурации mcp.json
  5. Вставьте скопированный JSON и сохраните файл

Где лежит файл, если открывать вручную:

Mac~/.cursor/mcp.json
Windows%USERPROFILE%\.cursor\mcp.json
Если в файле уже есть другие MCP-серверы — не затирайте весь файл. Добавьте блок "mmtable": { ... } внутрь существующего "mcpServers" и поставьте запятую между серверами.

5 Перезапустите и проверьте

  1. Полностью закройте Cursor и откройте снова (или Reload Window)
  2. Снова: Settings → Tools & MCP
  3. У сервера mmtable должен быть зелёный индикатор / список tools
  4. В Agent-чате напишите, например:
Покажи мои документы в MM Table
Если агент вызвал инструмент вроде list_documents и показал список — всё работает.

? Частые проблемы

Красный индикатор / не подключается

Проверьте, что в Authorization есть слово Bearer и пробел перед токеном. Пример: Bearer mmt_.... Перезапустите Cursor после сохранения.

Токен потерялся

Создайте новый в Профиле MM Table. Старый при желании отзовите в списке токенов.

Агент не видит документы

Убедитесь, что вошли в MM Table тем же аккаунтом, для которого создан токен. Документы другого человека агент не увидит, пока вам не выдадут доступ.

Ошибка JSON в mcp.json

Чаще всего лишняя запятая в конце. Проверьте запятые между серверами и кавычки.

Быстрая шпаргалка
