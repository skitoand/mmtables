Подключить MM Table к ChatGPT

Инструкция со скриншотами: стрелки и подсказки на картинках показывают, куда нажимать.

https://mmtable.crystalsystems.ru/mcp
Нужен платный ChatGPT и Developer mode. В UI названия могут быть Apps / Connectors / Plugins — смысл один. Auth выбирайте OAuth, не API key.

1 Settings → Apps

  1. Откройте chatgpt.com
  2. Аватар → Settings
  3. Слева выберите Apps

2 Включите Developer mode

  1. Откройте Advanced settings
  2. Включите переключатель Developer mode

3 Нажмите Create

  1. Вернитесь к списку Apps
  2. Нажмите Create

4 URL и OAuth

ПолеЗначение
NameMM Table
DescriptionДокументы, таблицы и бизнес-процессы
MCP server URLhttps://mmtable.crystalsystems.ru/mcp
AuthenticationOAuth

5 Войдите в MM Table

  1. Откроется страница OAuth MM Table
  2. Введите email/пароль от mmtable.crystalsystems.ru
  3. Нажмите Войти и продолжить / Разрешить

6 Включите в чате

  1. В диалоге нажмите +
  2. Выберите Developer mode
  3. Включите MM Table
  4. Напишите: «Создай бизнес-процесс из 5 этапов…»
