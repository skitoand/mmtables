    Настройки фильтра

    Для поля «Дата» задайте интервал, внутри которого на виджете можно двигать ползунок.

    Для списковых полей на виджете появится выбор значений с галочками, как в фильтре таблицы.

    По умолчанию фильтр применяется ко всем элементам Bitrix24 на рабочем столе, включая новые. Снимите галочку, чтобы исключить элемент.
